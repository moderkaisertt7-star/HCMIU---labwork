## 📚 Overview & Directory Structure

This repository contains the complete collection of academic laboratory exercises, midterm projects, assignments, and practical engineering coursework completed during the academic curriculum.

### 1. EE084IU_Microprocessing_Systems_Lab (TN Hệ Thống Vi Xử Lý)
- **Lab 4:** Timer, Counter & PWM configuration on ATmega32 / PIC. Detailed lab reports, calculations, oscilloscope waveforms, and duty cycle analysis.
- **Lab 5:** External and internal interrupts on ATmega32. Detailed registers (MCUCR, GICR, GIFR), ISR routines, and circuit validation.

### 2. EE091IU_Electronics_Devices_Lab (TN Linh Kiện Điện Tử)
- **Lab 1 & 2:** Diode characteristics, rectification circuits, and clipping/clamping behavior.
- **Lab 3:** BJT characteristics and DC operating points (Q-point, load line).
- **Lab 4:** BJT biasing configurations and switching dynamics.
- **Lab 5:** BJT AC small-signal amplification and frequency response analysis.

### 3. IT091IU_Programming_for_Engineers_Lab (TH Lập Trình Cho Kỹ Sư - C/C++)
- **Lab 1 - Lab 5:** Fundamental to advanced C programming for engineering applications.
- **Pointers & Memory:** Single variable pointers, pointer arithmetic, dynamic allocation, function pointers, and algorithm implementations with comprehensive screenshots and test cases.

### 4. EE083IU_Microprocessing_Systems (Lý Thuyết Hệ Thống Vi Xử Lý)
- **Midterm Project:** Smart Parking Barrier System using PIC16F877A / ATmega32. Complete Assembly/C firmware, Proteus schematic, hardware theory explanation, and presentation script.
- **Final Exam Homework 1:** Detailed step-by-step hand assembly encoding of ATmega32 instructions (Opcode, Machine Code, Addressing modes).

### 5. MA026IU_Probability (Xác Suất Thống Kê & Ứng Dụng)
- **HW2:** Discrete-Time Markov Chains (DTMC). Detailed state transition matrices, Chapman-Kolmogorov equations, absorbing states, and limiting distributions.

### 6. Archive_Previous_Semesters
- **C_Programming_Lab:** Earlier semester C code, exercises, and lab reports.
- **Electronic_Devices_Lab_Previous:** Earlier lab manuals, raw measurement data, and draft reports.
- **Microprocessing_Lab_Previous:** Firmware samples, legacy simulation models, and reference documentation.
